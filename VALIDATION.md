# Результати перевірок

Середовище: Flutter 3.47.4 stable / Dart 3.13.3, macOS x64.

## Виконано успішно

- Форматування всіх Dart-файлів: змін не потрібно.
- Статичний аналіз усього проєкту: `No issues found!`.
- `dart test test/core_test.dart --reporter expanded`: **9 тестів пройдено**.
  Перевірено порожні колекції, точні описи, where/map, повторні роки,
  нормалізацію міста, ArgumentError, структуру погоди, межі температур,
  затримку відповіді, інтервали та завершення потоків, times=0 і times<0.
- Консольний приклад бібліотеки: коректні описи, null для порожньої колекції,
  найстаріша книга за 2022 рік, порожній результат для 1999 року.
- Консольний приклад погоди: словник для Києва, очікувана помилка порожнього міста,
  три температури з інтервалом близько секунди, нормальне завершення потоку.
- `flutter build web`: вебзбірка створена успішно, Wasm dry run succeeded.
  Збірник показав попередження про відсутній шрифт CupertinoIcons;
  застосунок використовує Material Icons і не залежить від CupertinoIcons.
- PDF: 12 сторінок, вбудовані кириличні шрифти. Перевірено рендеринг,
  відсутність обрізання тексту та коду, ПІБ і групу, колонтитули.

## Межі перевірки

9 перевірок віджетів і навігації в `test/practical_test.dart` підготовлено
та перевірено аналізатором, але їх проходження у цьому середовищі не підтверджено:

- нативний flutter_tester аварійно завершується в CpuInfo::FieldContains
  ще до виконання тестів (SIGABRT);
- альтернативний запуск тестів через Chrome не зміг запустити локальний браузер.

Це не зараховано до успішно пройдених тестів. Для перевірки на звичайному
локальному середовищі запустіть:

```sh
flutter pub get
flutter test --reporter expanded
# або
flutter test --platform chrome --reporter expanded
```

Успішна вебзбірка підтверджує компіляцію Flutter-коду; вона не замінює
інтерактивної демонстрації. Фактичний запис екрана, GitHub-публікація й
мобільна збірка Android/iOS не виконані.
